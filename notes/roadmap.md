# 🗺️ Career Roadmap — B.Tech Sem 1 → Job-Ready

Structured for a 1st-semester student starting from absolute zero. ~1 hr/day pace.

## Sem 1 (now) — Foundations
**Goal:** be dangerous with a terminal and understand how networks talk.
- Linux: **OverTheWire Bandit** (levels 0→20) — learn commands by playing
- Networking: TCP/IP, DNS, HTTP basics (any free course/YouTube series)
- Python: basics — you'll need scripting from sem 3 onward
- Habit: `lab-journal.md` entry after every session. Non-negotiable.

## Sem 2 — Core security skills
**Goal:** complete guided attack chains and understand WHY they work.
- **PortSwigger Web Security Academy** (free, browser-based) — web fundamentals
- Tools with understanding: nmap, Wireshark, gobuster, Burp Suite
- **VulnHub** easy machines inside this lab (host-only network, fully legal)
- First solo CTF challenges; writeups in `notes/` and on GitHub.

## Sem 3 — Pick your lane (+ portfolio)
**Goal:** choose red or blue, and become findable.
- **Red team:** eJPT-style skills, harder VulnHub/HTB machines
- **Blue team:** SOC fundamentals, Wireshark deep dives, SIEM basics
- Portfolio: every script + writeup pushed to this repo. Recruiters read it first.

## Sem 4 — Certification + harder practice
**Goal:** paper proof + independence.
- CompTIA **Security+** (the standard HR filter) — study alongside labs
- **HackTheBox** easy machines (less hand-holding — right time for it)
- Advanced tooling experiments (snapshot first!)

## Sem 5–6 — Real-world proof
**Goal:** internship or meaningful project.
- Build 2–3 Python security tools (port scanner, log analyzer, subdomain enum)
- College CTF club / national CTFs — team experience matters in interviews
- Internship applications: portfolio + rank + writeups carry you

## Sem 7–8 — Landing the job
**Goal:** offers.
- Interview prep: networking + Linux + web fundamentals get asked constantly
- Target roles: SOC Analyst L1, Junior Pentester, Security Engineer intern
- Keep learning in public — this repo is your proof of work.

## The one rule that decides everything
**Consistency beats intensity.** 1 focused hour daily for 8 semesters beats
all-nighters before exams. The journal is how you see the streak grow.

## Communities worth joining (free)
- OverTheWire forums + r/cybersecurity (career threads)
- Local: college cyber club / CTF team — start one if it doesn't exist
