# 🛡️ CyberLab — Notes & Learning HQ

This folder is the brain of the lab. Your dashboard (`index.html` in the repo
root) shows the big picture; these files hold the details.

## What's in this folder
| File | Purpose |
|------|---------|
| `cheatsheet.md` | The ~20 Linux commands you'll actually use, with examples |
| `local-lab-guide.md` | How this Kali VM was built — and how to use/reset/rebuild it |
| `roadmap.md` | Semester-by-semester path to a cybersecurity career |
| `lab-journal.md` | Daily log — write something EVERY time you study |
| `future-local-lab.md` | Cloud & advanced options for later semesters |

## The Golden Rules (same ones on the dashboard)
1. Scan or attack ONLY machines inside this lab (your own VMs). Nothing else. Ever.
2. Never target college, hostel, or public WiFi, or any real website.
3. Snapshot before experiments; revert after mistakes. The VM is disposable.
4. Notes the same day. A lesson you can't explain is a lesson you lost.
5. Keep every capture/sample in its labeled folder — tidy lab, tidy mind.

## Where things live
- Lab root: `D:\CyberLab` — alias: type `cyberlab` in Git Bash
- VM files: `D:\CyberLab\vm` (auto-managed by scripts — don't move them)
- Downloads: `D:\CyberLab\downloads` (cleaned automatically after extraction)
- Inside Kali, your work folders mirror this structure under `~/CyberLab`
